# GNOME Noise

Listen to different sounds - Focus & Relax

## About

GNOME Noise is an Android app inspired by [Blanket](https://github.com/rafaelmardojai/blanket) that helps you focus and relax by playing ambient sounds. Perfect for productivity, studying, meditation, or falling asleep.

## Features

- **14 Ambient Sounds**: Rain, Storm, Waves, Stream, Wind, Fireplace, Birds, Summer Night, White Noise, Pink Noise, Coffee Shop, City, Train, Boat
- **Volume Control**: Adjust playback volume to your preference
- **Dark Mode**: Automatic dark/light theme based on system settings
- **GNOME-inspired UI**: Clean, modern Material Design 3 interface

## Installation

### Debug APK
Download `gnome_noise.apk` from the releases and install it on your Android device.

### From Source
```bash
flutter pub get
flutter build apk --debug
```
